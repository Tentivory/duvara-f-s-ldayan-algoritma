# Duvara Fısıldayan Algoritma

## Resmi Açıklama

Bu depo, insanlığın en büyük sorunlarından birine çözüm üretmek amacıyla kurulmuştur: **Duvarlarla iletişim kuramamak**.

Yıllardır duvarlar sessiz kaldı. Biz konuştuk, bağırdık, şarkı söyledik. Onlar hiçbir şey demedi. Bu algoritma, o sessizliği anlamlı bir diyaloga çevirir. Ya da çevirmez. Ama çok ciddiye alır.

### Nasıl Çalışır?

1. Kodu çalıştır.
2. Duvara fısılda.
3. Duvarın cevabını bekle (bazen 4 saniye sürer, bu bilimseldir).
4. Anlamadığın cevapları da kabul et. Duvarlar böyledir.

```bash
python3 duvara_fisilda.py
```

### Özellikler

- Gerçek zamanlı duvar dinleme
- Rastgele felsefi sessizlikler
- Tuğla kıpırdama simülasyonu
- Hiçbir API'ye bağlı değil (çünkü duvarlar offline)
- 100% organik, katkısız absürtlük

### Uyarı

Bu yazılım, duvarların duygusal durumunu değiştirebilir. Kullanımından önce en yakın psikoloğunuza danışın. Duvarlar da danışabilir.

### Katkıda Bulunma

Pull request'ler kabul edilir. Ama duvar onaylamazsa merge edilmez.
